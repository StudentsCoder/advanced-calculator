# 🧮 Advanced Calculator

A modern and responsive calculator built using **HTML**, **CSS**, and **JavaScript**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 📊 Percentage
- √ Square Root
- x² Square
- 1/x Reciprocal
- ⌫ Backspace
- ⌨ Keyboard Support
- 📱 Responsive Design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Advanced-Calculator/
│── index.html
│── style.css
│── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it with Live Server in VS Code.
